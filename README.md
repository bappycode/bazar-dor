বাজার দর (BazarDor) 🛒

BazarDor is a web application designed to help users explore and compare market prices of everyday products in Bangladesh. It provides an easy way to check product prices, compare prices across different markets, and make informed purchasing decisions.

🚀 Technologies Used

- Next.js — React framework for building the web application
- React — Building interactive user interfaces
- JavaScript — Application logic
- Tailwind CSS — Styling and responsive design
- REST API — Fetching product and market price data

✨ Key Features

1. Product Price Browsing — Explore products and their current market prices.
2. Market Price Comparison — Compare product prices across different markets.
3. Minimum Price Tracking — Quickly identify the lowest available price for a product.
4. Product Search — Find products easily and quickly.
5. Responsive Design — Enjoy a smooth experience on desktop, tablet, and mobile devices.
